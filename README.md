## Overview

AIR Transfuser imports audio loops, slices them to a beat grid, and maps each slice to a pad for real-time remix performance with per-pad pitch, filter, and reverb for live mangling.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **AIR Transfuser** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Beat Slicer** | Auto-slice loops to transients or a configurable beat grid |
| **Pad Mapping** | Map slices to pads with velocity sensitivity and round-robin |
| **Per-Pad FX** | Independent filter, pitch, and reverb controls per slice pad |
| **Loop Sync** | BPM-locked playback with stretch and pitch-shift per slice |
